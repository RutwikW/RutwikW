## 🧭 About Me

I'm a software engineer who builds **agentic AI systems**, from architecture through
release. I like taking hard, ambiguous problems and turning them into reliable, production
systems: autonomous agents that plan, call tools, recover from failure, and ship behind
real evaluation gates.

- 🔷 **AI Agent Engineer @ Microsoft.** Building production autonomous security agents:
  planner/executor loops, tool orchestration, multi-agent decomposition, durable run state,
  and CI eval/release gates.
- 🏡 **Founding Software Engineer @ Sanmore.** Took an ML property valuation platform from
  a blank repo to production, cutting appraisal turnaround from days to under a minute.
- 🤖 **RAG systems @ OpenAI:** retrieval pipelines grounding LLM responses in external
  knowledge.
- 🚀 **Co-founder & CTO @ Waynix:** an AI travel-planning app that turns short-form
  video content into personalized itineraries.

> I care about agent reliability: state models, typed tool contracts, retries/recovery,
> guardrails, and evals that actually catch regressions before they ship.
